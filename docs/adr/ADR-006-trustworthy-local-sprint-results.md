# ADR-006：用版本差与可校验成果卡实现本地冲刺

状态：已接受（1.1.0）

## 背景

原始调研建议安静自习室、拼字冲刺和小组目标。当前产品没有账号、中继或在线 presence，不能把一个本地计时器包装成在线房间，也不能把自填昵称包装成认证成员。

## 决策

1. 冲刺是项目内本地会话，只允许一个活动会话；范围为一个场景或整个项目；
2. 产出以开始/结束已保存版本的字数差计算，不采集按键、剪贴板或正文内容；
3. 计时使用服务端墙钟、累计暂停时长和不可变事件；睡眠/页面离开保守暂停，时钟回拨显式报错；
4. 结束生成严格、无正文的 `bbd-sprint-v1`，用事件哈希链和整卡哈希检测意外篡改；
5. 离线小组看板只手动导入成果卡，按不可变 ID 幂等累计，参与者名称始终标为自填标签；
6. 普通备份包含冲刺历史和看板；移动端只读显示本机最近结果；
7. 本地通知必须由用户授权，到时仅提醒，不自动结束或写正文。

## 后果

- 粘贴、撤销、删除和跨多次保存仍得到可解释净新增；
- 系统睡眠不会被伪造成连续专注时长；
- 无账号也能进行低风险的小组目标交换；
- 成果卡没有数字签名，不能作为认证身份或防作弊证明；
- 真实在线房间、邀请撤回、成员权限和排行榜必须等账号与中继完成后另行设计。
