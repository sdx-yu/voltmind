# ADR-011：用冻结波次与产品外名册执行真实研究

状态：已接受（1.6.0）

## 决策

笔不怠在本机保存无个人身份信息的波次控制面：随机 ID/展示码、真实/演练类型、14–42 天 UTC 窗口、目标、固定分层配额、四项准备确认、受限状态机、固定异常码和前向哈希事件。参与者首次归属不可换波次，类型、窗口与分层配额在导入时再次校验；归属事件保存波次域二次哈希承诺，不复制参与者哈希。

招募、姓名、联系方式、身份核对、同意原件、原始研究包与安全交付渠道继续留在产品外。工程演练与夹具在数据模型、界面和汇总中独立，永不计入真实执行。产品不发送邀请、不自动判断真人，也不根据数值自动改变 R1 NO-GO。

## 理由

R1-B 已能严格聚合包，但没有“这一包属于哪轮冻结研究”的可审计边界。把波次和名册都做进产品会扩大个人信息、删除和访问控制风险；只做计划文档又无法阻止跨窗口、错类型、超配额和换波次。无名册控制面能在不扩大敏感数据面的前提下，让执行状态与研究证据建立可验证联系。

## 后果

- 负责人必须维护独立的受控名册与删除流程，产品不能替代运营责任；
- 真实时间、身份与招募证据仍是外部门，自动化只能验收工程能力；
- 波次事件不可变，参与者删除后仍保留不可逆关联承诺，用于证明曾发生一次归属而不能恢复参与者哈希；
- 公开发布仍需要真实周期、人工研究结论、Developer ID/公证、Windows 签名与真机矩阵。
