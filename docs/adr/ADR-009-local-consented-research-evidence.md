# ADR-009：真实验证先建立本机同意与最小披露证据

状态：已接受（1.4.0）

## 决策

1. R1 不启用后台遥测；研究记录默认只保存在本机；
2. 参与者以随机码表示，不收直接身份字段；
3. 只记录固定任务和有上限的量化指标，不提供可能夹带正文的自由文本；
4. 项目只形成参与者域内不可逆范围指纹，项目身份不导出；
5. 研究事件和包使用 SHA-256 完整性链，但明确不把哈希冒充身份签名或真实使用证明；
6. 作者主动导出，随时可以退出并清除本机研究数据；
7. 自动化、浏览器和开发者自测只能验收基础设施，不能通过 R1 的真实作者门。

## 原因

R1 的目标是验证真实价值，而不是增加遥测覆盖。正文、设定和创作习惯高度敏感；先让作者看见、控制并最小化数据，才能在不破坏本地优先承诺的前提下取得可复核证据。
