# ADR-001：先以本机 Node + SQLite 交付可验收 MVP

- 日期：2026-08-26
- 状态：接受，MVP 阶段

## 背景

产品基线将 Tauri 2 列为待 spike 的桌面候选。当前开发环境具备 Node.js 24 与 SQLite 3.50，但没有 Rust 工具链。MVP 的最高风险是稿件可靠性、中文输入、正典事务与 AI 越权，而不是安装包外壳。

## 决定

- 本机 Node 服务持有 SQLite、文件、备份、凭据和 AI Provider；
- React + Tiptap 提供只绑定 `127.0.0.1` 的本地界面；
- 生产构建由本机服务静态托管，不依赖云端；
- 核心模块保持 API 与 UI 解耦，后续可由 Tauri sidecar 或原生核心替换；
- 完整数据仍在本机，浏览器不是权威存储。

## 后果

- 可以立即实现并测试 SQLite 事务、FTS、恢复和本地 AI；
- MVP 首个可验收版本以本地服务启动，不承诺原生安装包；
- V1 前必须单独完成 Tauri 中文输入、更新、文件系统与签名 spike；
- 服务只监听 loopback，必须启用本地会话令牌和 Origin 校验，避免其他网页调用本地 API。

## 回滚

若本地服务形态影响真实用户采用，保留数据库和应用层，将 UI/API 桥接迁移到 Tauri；数据格式不变。
