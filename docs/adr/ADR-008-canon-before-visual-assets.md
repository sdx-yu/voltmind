# ADR-008：视觉资产服从文字正典并采用候选绑定

状态：已接受（1.3.0）

## 背景

长篇作者需要角色、地点、物品的视觉一致性和场景分镜，但生成图存在事实漂移、版权、隐私和供应商数据保留风险。如果图片能反向覆盖正典，视觉误差会进入后续一致性检查和 AI 上下文，破坏产品的核心闭环。

## 决策

1. 文字正典是唯一事实上游；视觉描述只读取作者明确勾选且非 `local_private` 的字段；
2. 图片导入后先成为候选，作者接受才绑定锚点；接受操作不调用任何正典写入路径；
3. 绑定冻结 `canonHash`，正典变化后显示过期并要求新候选，不自动把旧图升级；
4. 原图按字节 SHA-256 内容寻址，只接受服务端验证的 PNG/JPEG，不接受 SVG 或活动内容；
5. 故事板只保存镜头元数据、锚点和资产引用，不复制正文；
6. 1.3.0 不接入远程图像 Provider，避免在版权、审核、费用、凭据和数据保留未冻结时伪造生成能力。

## 结果

优点是视觉能力不会污染正典，备份可验证且重复图片只存一次；作者能明确看到当前/过期绑定。代价是生成需要外部手动步骤、旧图在正典变化后必须复核，SQLite 备份可能变大。未来远程 Provider 必须新增独立 ADR 和隐私验收，不能绕过本决策。
