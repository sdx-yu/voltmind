# ADR-010：真实作者证据采用人工声明与连续链隔离

状态：已接受（1.5.0）

## 决策

R1-B 不建设账号、云遥测或自动身份认证。研究负责人只导入作者主动交付的 `bbd-research-v1`，首次把证据固定为 `external_attested` 或 `engineering_fixture`；真实外部类必须完成目标作者、独立参与、稿件权利和真实使用四项人工声明。同一参与者的后续包必须严格扩展既有事件哈希前缀。

负责人库不保存参与码原文、原始研究包、书名、正文、项目/任务 ID 或自由文本。周期门只读取最新连续提交的有界摘要；工程夹具、到期记录和已删除记录不计数。达到试点数值也不自动改变 R1 NO-GO。

## 原因

产品当前没有可信账号、招募系统或远程证明。把匿名码、截图或自动化当成真人证据会制造不可审计结论；保存原始包又会不必要地扩大敏感数据面。人工声明不能证明身份，但能明确责任边界，连续链可阻断同一匿名身份的回退和分叉，夹具隔离可让工程测试不污染真实门禁。

## 后果

- 研究负责人必须在产品外访问控制招募、同意与原始包，并执行相应删除；
- 双哈希删除回执会永久阻止当前负责人库重收同一参与码；如确需重新参加，应重新走同意并生成新码；
- 本机工具只能算固定门，不能得出因果、付费意愿、独立人数或公开发布结论；
- R1-C 的真实执行需要外部人员与周期，无法由自动化验收替代。
