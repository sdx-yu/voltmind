# 移动收集与审阅指南（0.9.0）

## 能做什么

移动首页只有三项主要工作：快速记录灵感或场景想法、继续阅读最近缓存的场景、处理待整理内容。打开场景是只读的；审阅笔记会进入收集箱，不会直接改动正文、正典或来源链。

## 安装与离线

在支持 PWA 的浏览器通过 HTTPS 或本机回环地址打开 `?mobile=1`，使用浏览器的“安装应用/添加到主屏幕”。首次成功加载会缓存完整启动 shell；之后服务暂不可达时仍可打开和记录。0.9.0 不提供公网地址、账号或自动云托管，因此手机真机访问仍需要后续部署入口。

状态含义：

- `已同步`：本机事件已提交到当前笔不怠数据服务；
- `回流中`：正在提交本机事件或更新只读目录；
- `仅本机` / `离线可用`：可以继续记录，恢复连接后自动重放；
- `设备可用空间偏低`：释放空间后再大量记录；保存失败时界面会明确说明“尚未保存”。

## 更新与恢复

新版本下载完成后，页面显示“立即更新”。未确认前仍使用当前版本；安装失败时继续使用上一可启动 shell。本地缓存异常时可选择“重建缓存”，但这会删除尚未回流的移动记录，应先恢复数据服务并确认回流，或手工抄录重要内容。

普通 `.bbd-backup` 会包含已归属当前项目的移动记录及处理动作，并在恢复时重映射场景；未归类记录不进入单项目普通备份。加密 `.bbd-sync` 接力包可携带当前项目和未归类记录，恢复短语丢失时无法解密。

## 0.9.0 边界

不包含推送、账号、真实云中继、多人评论、移动全文编辑、应用商店发布或真实 iOS/Android 兼容性承诺。它们必须通过独立部署、安全和真机验收后才能开放。
