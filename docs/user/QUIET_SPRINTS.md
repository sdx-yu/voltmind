# 安静冲刺与离线小组目标指南

## 开始冲刺

1. 打开项目，在“交付”中选择“安静冲刺”；
2. 选择一个场景或整个项目，设置 10–120 分钟和净新增目标；
3. 点击“开始并进入安静写作”。写作台右下角会显示剩余时间、净新增和目标；
4. 正文继续自动保存和留版本，冲刺不会锁住退出、撤销、搜索或紧急操作。

净新增来自开始与当前已保存版本的字数差。粘贴不会按按键次数重复累计；撤销、删除会从结果中抵消。

## 暂停、睡眠与结束

- 可随时暂停或恢复；
- 页面长时间离开或电脑睡眠后，未知时段会被排除并保守暂停；核对提示后再显式恢复；
- 系统时钟异常时同样暂停，不会伪造一段连续写作；
- 到时只发应用内提醒；允许系统通知后也可收到本地通知；
- 点击“结束”才生成成果卡；点击“取消”不删除正文或已有版本。

## 成果卡

成果卡包含笔名标签、时间、净新增、目标和事件链，不含书名、场景名或正文。导出的 `.bbd-sprint` 可以手动交给其他人。

成果卡能发现文件在导出后被修改，但不是数字签名，也不能证明笔名对应某个真实成员或产出没有作弊。

## 离线小组看板

1. 创建“今日”或“本周”看板并设置目标；
2. 本机成果可直接“加入看板”；其他人的 `.bbd-sprint` 先读取和校验，再加入；
3. 同一张卡重复导入不会重复累计；同 ID 异内容会被阻断；
4. 看板按自填参与者标签汇总字数和次数，不显示在线人数或排行榜身份认证。

冲刺历史、成果和看板进入完整离线备份。恢复时成为恢复项目内的独立历史；结果卡仍不包含正文。
