# 角色化审阅接力指南

## 作者

1. 打开“交付 → 角色审阅”，填写审阅者、选择角色和最少必要场景。
2. 生成任务包后立即保存一次性恢复短语；任务包与短语通过不同渠道发送。
3. 收到回应包后，在“作者处理”导入。系统先解密并核对会话、角色、范围和项目指纹。
4. 逐条查看原文、意见、替换建议和锚点状态，再选择采纳、拒绝或暂缓。

采纳改写建议会形成新版本和来源事件；拒绝、暂缓与评论采纳都不会改写正文。锚点失效的改写建议必须先人工找到原文，当前版本不会自动套用。

## 审阅者

1. 在“审阅者工作台”选择作者发来的 `.bbd-review` 任务包并输入恢复短语。
2. 选择授权场景和段落，把要评论的连续原文复制到“引用原文”。
3. 填写评论；Editor 和 Co-Writer 还可填写局部替换建议，Beta Reader 只能评论。
4. 意见先保存在隔离副本。填写同一恢复短语并导出回应包，再发回作者。

审阅者看不到作者未选择的场景，也不能直接改正文、正典或来源记录。

## 安全提示

- 恢复短语不会保存在包内，也不会进入普通备份；遗失后只能请作者重新建立任务。
- 离线副本发出后不能远程撤回，不要把不必要的敏感场景放入任务。
- 系统中的审阅者名称只是本地标签，不等同于经过认证的真实身份。
