# 视觉锚点与故事板指南

## 建立视觉锚点

1. 在“交付 → 视觉故事板”点击“建立视觉锚点”；
2. 选择人物、地点或物品。标记“仅本地”的正典不能用于视觉描述；
3. 逐项勾选简介、别名或状态。正典名称必须明确包含，未勾选字段不会被读取；
4. 可写入画风、色调等作者要求，然后绑定当前文字正典。

页面会显示可复制的本地视觉描述和正典哈希。1.3.0 不会把描述发送到任何图像服务；如需生成，请自行选择并确认外部工具的条款。

## 导入与决定候选

- 只选择 PNG/JPEG，最大 10 MiB；扩展名与真实内容不一致会被拒绝；
- 导入后图片处于“待作者决定”，不会自动成为定稿；
- 点击接受后，图片只绑定当前正典版本，不修改正典文字；
- 点击拒绝会保留决定记录；新定稿会把旧定稿标记为历史版本；
- 如果正典的已选字段变化，锚点显示“待复核”。先刷新视觉描述，再导入并接受符合新正典的候选。刷新本身不会让旧图重新变为当前定稿。

## 制作场景故事板

1. 选择场景并建立故事板；
2. 写镜头目的，可选择一个视觉锚点和已接受图片；
3. 备注只写调度、连续性或构图意图，不必粘贴正文；
4. 使用上下按钮调整叙述顺序，或删除单张分镜卡。

故事板不会复制场景正文。删除卡片也不会删除图片、正典或锚点。

## 备份与隐私

完整离线备份会包含项目使用的原始图片，因此文件体积可能明显增加。恢复时会复核图片 SHA-256、真实 MIME、尺寸与正典绑定。图片来源标签和 SHA-256 不证明版权或作者身份；公开使用前仍需自行确认素材授权。
