# 真实作者验证指南

从书架点击“R1 真实验证”。加入前请完整阅读固定同意文本并逐项确认。应用不会要求姓名或邮箱，只生成一个随机参与码。

## 记录真实任务

1. 选择自己拥有权利或已获授权的本机项目；
2. 选择实际准备完成的任务，然后点击“开始计时”；
3. 正常使用笔不怠完成任务；
4. 如实选择完成或中止、是否达到目标、难度、预估节省时间和问题码；
5. 不需要、也没有入口填写正文或人名。

研究包只含匿名参与码、同意回执、任务指标、不可逆项目范围指纹和哈希链。主动导出不等于自动上传，也不代表 R1 已通过；只把包交给你确认的研究负责人。

“无正文支持诊断”只含版本、系统架构、数据库完整性、快照情况和数量统计，不含标题、ID、正文、Prompt、密钥或数据目录路径。

## 退出

点击“退出验证”并再次确认，会删除当前数据库中的参与码、任务和研究事件，不影响书稿或版本。已有历史数据库快照仍按备份保留策略存在，需要另行管理；此前主动交出的离线包也需要联系接收者删除。
