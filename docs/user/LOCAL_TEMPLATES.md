# 本地结构模板指南

## 使用内置示例

1. 打开项目的“交付”页，选择“结构模板”；
2. 在本地目录选择“三幕结构起步包”；
3. 阅读发布者、许可证、包哈希和“非认证身份”提示；
4. 在“当前项目授权”中逐项开启确实需要的能力；
5. 点击“生成预览”，检查所有待建章节、场景、状态和规则结果；
6. 有同名章节时，明确勾选添加“（模板）”后缀；
7. 点击“确认并单事务创建”。模板只创建空白计划节点，不写入或覆盖正文。

## 导入别人的包

选择 `.json` 或 `.bbd-template` 文件后，笔不怠先执行严格格式、引用、大小和两层 SHA-256 校验。预检会显示包名、版本、作者自述、许可证、节点数、规则数以及重复/碰撞状态。只有预检通过后才出现安装动作。

相同包重复导入是幂等的；如果包 ID 和版本相同但内容不同，会被视为碰撞并阻止覆盖。作者标签和来源网址不是认证身份，许可证也仍需接收者自行判断。

## 权限含义

- “读取所选项目摘要”不含正文或正典详情；
- “创建计划节点”只能新建空白章/场景；
- “运行本地规则”只执行内置计数和重复标题检查；
- 正文、网络、密钥、恢复短语、任意文件和系统命令始终不可授权。

安装、启用和授权是三件不同的事。授权只作用于当前项目，撤销后下一次预览/应用立即受限。

## 撤销与卸载

“整批移入回收站”会把该次应用创建的节点及其后代软删除；其中已有的内容仍可从项目回收站恢复。撤销不会抹去应用记录和来源事件。

停用阻止继续预览与应用；卸载把包从可用目录移除。两者都不会静默删除已创建的书稿节点。普通项目备份包含相关包、授权和应用记录，恢复后仍可审计。
