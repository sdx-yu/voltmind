# 笔不怠 1.3.0 隐私说明

- 正文、正典、版本、快照和导入原件默认只存本机；产品当前没有遥测或自动崩溃上传。
- AI 默认使用离线演示模型。配置外部 Provider 后，只有上下文胶囊中主动勾选、且不属于 `local_private` 的内容会发送到该 Provider。
- API Key 不返回前端、不写日志；macOS 生产版用系统钥匙串保护主密钥，数据库只保存 AES-256-GCM 密文。
- 本地服务只监听随机 `127.0.0.1` 端口，并使用 HttpOnly、SameSite=Strict 会话 Cookie 和 Origin 白名单。
- 故障反馈默认只需要版本、系统、项目规模和复现步骤，不应附带正文、密钥或完整数据目录。
- “来源”页默认只导出动作、时间、关系与哈希。正文摘录必须由作者显式勾选，每个版本最多 500 字；Prompt、API Key 和 AI 输出全文不进入来源包。
- `bbd-provenance-v1` 只能校验本地记录是否被修改，不宣称自动取得版权、司法效力或平台原创认证。
- “接力”是 0.8.0 的本地工程实验，不是云服务。只有作者主动导出的 `.bbd-sync` 文件会离开本机；项目标题、正文、正典、来源事件和附件都位于 AES-256-GCM 密文中。
- 恢复短语只显示一次，不写入数据库、普通备份或日志。中转文件可见项目指纹、设备名称/ID、序号、版本向量、盐、验证值、块清单和密文大小，因此仍会泄露传输时间、近似数据量和设备间关联等元数据。

0.9.0 的移动 PWA 将收集项、处理动作和最近只读场景缓存在浏览器 IndexedDB；这些内容不会自动上传到第三方。连接作者自己的笔不怠数据服务时，事件会回流至本地 SQLite；只有作者主动导出的加密接力包才会离开该服务。

1.0.0 的 `.bbd-review` 任务与回应使用 scrypt 派生密钥和 AES-256-GCM 加密。信封仍会暴露协议版本、随机会话/包标识、加盐项目指纹、创建时间与近似密文大小；项目标题、审阅者标签、角色、场景和意见在密文中。恢复短语不进包、不进普通备份。离线副本发出后无法远程撤回，作者应只选择必要场景。

1.0.0 不包含帐号体系、自动上传、遥测、真实云同步或经过认证的审阅者身份。未来部署手机可访问入口、中继、推送、遥测或诊断上传前必须重新进行隐私与安全验收。

1.1.0 的冲刺只保存时间、范围、本机版本快照、字数和事件，不采集按键或剪贴板。`.bbd-sprint` 默认排除书名、场景名、正文、正典、Prompt、设备 ID、本地项目/场景 ID和密钥，只含脱敏指纹、结果摘要与哈希链。自填笔名不是认证身份，哈希也不是数字签名或防作弊证明。只有作者主动导出并传递成果卡时，这些结果元数据才会离开本机。

1.2.0 的 `.bbd-template` 是本地声明式结构数据，不执行第三方代码。包只能请求当前项目的书名/简介/数量摘要、创建空白计划节点和运行固定本地规则；正文、网络、密钥、任意文件和系统命令没有可授权入口。发布者、来源和许可证都是包内自述，SHA-256 不是身份签名。只有作者主动导出或传递模板包时，结构元数据才会离开本机。

1.3.0 的视觉锚点只读取作者明确勾选且非 `local_private` 的人物、地点、物品字段；场景正文和未选择字段不会进入视觉描述或故事板。图片以 PNG/JPEG 原始字节保存在本地 SQLite，并随普通备份导出，可能显著增加备份体积。1.3.0 不连接远程图像 Provider；复制描述并交给外部工具属于作者主动的数据传递，受该工具的版权、审核和数据保留条款约束。图片 SHA-256 只证明本地内容完整性，不证明版权、来源或身份。
