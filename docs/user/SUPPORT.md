# 故障反馈与支持模板

请提供：

- 笔不怠版本（RC1 为 0.2.0）；
- 操作系统版本与 CPU 架构；
- 项目规模：项目数、章节数、约多少万字；
- 问题发生前的操作步骤、预期结果、实际结果；
- 是否处于救援模式，是否存在标记完整的快照。

请勿直接提供：正文全文、API Key、钥匙串内容、完整数据库或整个应用数据目录。若必须提供样本，应新建最小复现项目并移除真实人名与敏感内容。

RC1 桌面版的数据目录由系统管理；macOS 使用 `~/Library/Application Support/com.bibudai.writer/`。在救援或取证前请先复制该目录，不要直接修改其中的数据库文件。
