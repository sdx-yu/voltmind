# V2-V 文字正典驱动的视觉锚点与故事板（1.3.0）

状态：规格冻结。对应原始调研 V2 的第四项“文字正典驱动的角色视觉锚点与故事板”。视觉能力服务于长篇一致性，不把产品变成图片社区，也不让生成图反向静默改写文字正典。

## 目标

作者可以从已确认的人物、地点和物品正典建立本地视觉锚点，为场景制作不含正文的故事板卡；视觉生成或导入结果始终是候选资产，只有作者确认后才绑定正典版本。

## 实施范围

1. migration v13：视觉锚点、内容寻址资产、生成/导入候选、故事板和绑定事件；
2. 从显式选择的正典字段生成可见视觉描述，不读取 `local_private` 或未选择字段；
3. 本地导入图片、缩略图和 SHA-256 去重；可选图像 Provider 仍需明确数据流与凭据隔离；
4. 候选—对比—接受/拒绝；接受只绑定资产，不修改文字正典；
5. 场景故事板按叙述顺序排列，可标注镜头目的、人物锚点和连续性提醒；
6. 备份、隐私、无障碍、真实浏览器和桌面发布验收。

## 明确不做

- 图片广场、社交发布、模型训练、点赞、下载量或公开人物库；
- 未经确认用图片反推并覆盖人物外貌、服装、地点或剧情事实；
- 人脸身份识别、真人换脸、名人仿冒或不透明的远程素材抓取。

## 外部门

- 真实图像 Provider 的版权条款、内容审核、费用、地区可用性与供应商数据保留；
- 角色跨数十张图的一致性效果、专业分镜师可用性和真实作者留存；
- 对外分享、协作者权限与媒体 CDN。
