# `r1c-wave-v1` 受控波次协议

状态：R1-C 1.6.0 冻结。

每个波次由随机 ID 和展示码标识，不保存波次名称、招募渠道、作者姓名或联系方式。创建时冻结类型、UTC 起止窗口、目标人数、四个固定作者分层配额和 R1-C 协议哈希。

外部受控波次必须为 14–42 天、目标 5–10 人且配额总和精确匹配；工程演练允许 1–10 人，但永不计为真实执行。开放招募前四项负责人准备声明必须全部为真。波次事件使用顺序号、前向哈希和事件哈希记录创建、状态转换、异常开启/解决与参与者归属。

外部参与者只能归属外部波次，工程夹具只能归属工程演练，且每个分层不得超过冻结配额。首次归属后不可换波次；外部包的同意时间必须位于冻结窗口内。波次进度只读取未过期、类型相符且仍存在的最新连续提交。归属事件只保存按波次域二次哈希的关联承诺，不复制参与者哈希；参与者删除后不可由波次事件恢复原参与者哈希。

异常码固定为 `onboarding_blocked`、`support_request`、`recovery_failed`、`data_loss`、`privacy_request`、`protocol_deviation`，级别固定为低/中/高/严重。异常没有自由文本；未解决严重异常会阻止波次关闭。工具不自动联系参与者，也不自动修改 R1 NO-GO。

`bbd-wave-kit-v1` 只包含冻结时间窗、配额、协议哈希、参与者操作清单、支持与删除边界、隐私声明和 manifest SHA-256；不含名册、参与码、联系方式、正文、标题、项目/任务 ID、Prompt、密钥或路径。
