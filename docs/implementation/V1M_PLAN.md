# V1-M 移动收集与审阅（0.9.0）

状态：本机工程通过（0.9.0）。阶段依据原始调研中 V1 尚未完成的“移动端灵感收集与审阅”，不提前进入 V2 多人协作。

## 目标

让作者离开桌面时能快速收集灵感、查看当天写作和做私有审阅决定；设备离线时仍可用，并通过 `bbd-sync-v1` 与桌面副本接力，不把移动端变成缩小版全功能编辑器。

## 实施范围

1. 建立可安装 PWA、应用清单、离线 shell、升级提示和缓存版本回滚；
2. 增加“收集箱”：文字灵感、待办式场景想法和目标项目/节点，先存本机 IndexedDB；
3. 增加移动审阅：只读场景、来源/版本摘要、批注草稿和“稍后处理”决定；
4. 定义移动收集项的不可变 ID、状态和同步对象，接入 `bbd-sync-v1` 加密接力；
5. 保持四工作台桌面信息架构，移动首页只暴露“快速记、继续读、待处理”；
6. 完成离线重开、升级中断、缓存损坏、低存储、窄屏触控、键盘/安全区与桌面回归；
7. 形成安装、隐私和恢复说明；真实 iOS/Android 设备矩阵单列外部门。

## 验收门

- 飞行模式下启动、记录 20 条灵感、关闭重开后不丢失；
- 同一收集包重复/乱序导入幂等，桌面可定位到目标项目或进入未归类箱；
- 移动端默认不开放整书批量改写、正典覆盖或来源链重写；
- Service Worker 升级失败可回退到上一个可启动 shell，不阻断本地数据读取；
- 360/390/430px 触控流程和桌面主流程均通过自动化与真实浏览器验收。

## 明确不做

- 账号、自动云上传、推送通知和应用商店发布；
- Editor、Beta Reader、Co-Writer 角色、共享评论或实时合著；
- 在移动端复制桌面全部剧情、正典和交付管理能力。

## 外部门

- iOS Safari/主屏安装、Android Chrome/厂商 WebView 真机矩阵；
- 真实云中继、设备吊销和账号恢复；
- App Store/Play 商店封装、签名、审核与隐私申报。

## 完成证据

- migration v9、IndexedDB 双层本地存储、追加动作事件和 `bbd-sync-v1` 可选移动载荷已实现；
- 首装 shell 原子缓存、用户确认更新、上一 shell 回退、缓存异常和低存储提示已实现；
- 71 项自动化测试通过；360/390/430px 真实浏览器完成记录、只读审阅、决定、断服重开和联网回流，控制台无错误；
- 桌面主流程、0.8 接力兼容、普通备份恢复和 macOS 构建继续纳入发布门。
