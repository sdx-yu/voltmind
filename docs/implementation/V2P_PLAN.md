# V2-P 本地插件与结构模板包（1.2.0）

状态：本机工程通过（1.2.0）。对应原始调研 V2 的第三项“插件/模板市场、可共享的剧情结构模板”。已完成可校验、可撤销、最小权限的本地声明式模板包；没有服务端、审核和签名身份时，不伪造在线市场、下载量或官方认证。验收证据见[归档报告](../../归档/2026-08-27/笔不怠V2-P本地插件与结构模板包验收报告_v1.2.0.md)。

## 目标

作者可以导入、预检、启用和撤销本地结构模板包，把三幕式、英雄旅程、悬疑线索表等结构应用为新建草稿；插件只能通过受限能力清单访问显式选择的数据，不能读取整个数据目录、密钥或静默联网。

## 实施范围

1. migration v12：包清单、内容寻址资源、授权、安装记录与撤销日志；
2. 冻结 `bbd-template-v1`：结构节点、字段、版本、许可证、来源和完整性哈希；
3. 本地目录：导入、预检、冲突提示、启用/停用、卸载与回滚；
4. 最小能力模型：读所选项目摘要、创建计划节点、运行本地规则；默认无正文、无网络、无密钥；
5. 模板应用先预览 Diff，再以单事务创建，可整批撤销；
6. 备份、来源事件、无障碍、真实浏览器和桌面发布验收。

## 明确不做

- 在线商城、支付、下载量、评分、推荐算法或“官方认证”；
- 未签名远程代码、任意 Node/系统命令、任意文件系统和静默网络访问；
- 复杂排版商城或自动把模板覆盖到已有正文。

## 外部门

- 发布者身份、代码签名、恶意包扫描、审核/下架、版权投诉和供应链响应；
- 真实创作者模板生态、分成、四周留存和付费意愿。
