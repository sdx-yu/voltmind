# V1-E 创作来源链与可验证导出（0.7.0）

状态：已完成并通过工程验收（2026-08-26）。

## 目标

把现有版本、AI 候选、作者接受、人工改写、恢复和导入留痕整理成作者看得懂、第三方可校验但不泄露正文的创作来源链。

## 产品语义

- 来源说明是创作过程证据，不宣称自动取得版权、司法效力或平台原创认证；
- 以项目和场景时间线回放人写、AI 建议、作者接受/拒绝、接受后人工修订、导入、恢复和批量替换；
- 作者接受 AI 建议后再修改，来源不得退化成“纯人写”，应保留“AI 建议后人工修订”的链路；
- 默认导出元数据、哈希、时间、动作和版本关系，不默认把正文或 Prompt 放进证明包；
- 导出包含稳定格式版本、清单哈希和离线校验说明，任何修改都应导致校验失败；
- 旧版本与旧备份继续可读，来源事件和导出记录进入完整离线备份。

## 实施步骤

1. migration v7：规范化来源事件、父版本关系、来源标签与证明包导出记录；
2. 从 revisions、operation_log、ai_tasks、candidate_changes 和 imported_sources 建立兼容投影，不伪造历史中不存在的细节；
3. 场景版本历史增加来源筛选、相邻 Diff 和“AI 后人工修订”可解释链；
4. 项目增加创作回放时间线，支持按场景、动作和时间过滤并定位正文版本；
5. 导出 `bbd-provenance-v1` JSON 清单和可读报告，正文摘录由作者显式选择；
6. 提供独立离线校验命令/界面，覆盖篡改、缺失事件、旧备份与失败回滚；
7. 完成自动化、真实浏览器、桌面构建、隐私复核与报告归档。

## 验收主流程

人工写入正文 → 产生人写版本 → 生成并拒绝一条 AI 候选 → 接受另一条候选 → 作者继续修改 → 时间线显示完整来源链 → 相邻版本可回放和定位 → 导出不含正文的证明包 → 离线校验通过 → 修改清单后校验失败 → 备份恢复后事件关系与哈希不变。

## 明确不做

- 逐键盘录制、摄像头证明、后台监控或不可关闭的行为采集；
- 区块链上链、NFT、法律确权或“百分之百原创”承诺；
- 默认导出正文、Prompt、API Key、私密正典或未勾选的 AI 上下文；
- 为了补齐时间线而推断或伪造旧版本中没有记录的作者动作。

## 外部门

- 法律证据效力、平台原创认证和争议处理必须由相应机构或平台验证；
- 可信时间戳、第三方签章和硬件密钥属于后续可选集成，不作为 0.7.0 工程通过条件；
- 正式对外分发仍需要 Developer ID 签名与 Apple 公证。
