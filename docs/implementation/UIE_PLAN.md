# UI-E 质量门与收尾（2.1.0）

基线：[UI 统一规划与设计方案 v1.0](UI_SYSTEM_PLAN_V1.md)、[UI-D 长尾工作流统一](UID_PLAN.md)

状态：本机工程与 macOS Chrome 代表环境验收通过（2026-08-28）。

## 目标

把 UI-A～UI-D 的设计约束变为每次提交都可重复执行的质量门，覆盖视觉、可访问性、响应式、键盘与长文性能；真实设备或平台条件缺失时明确保留外部门。

## 已完成范围

1. 以 Playwright + Google Chrome 建立 7 张稳定截图：组件展厅四种代表状态，以及书架、编辑器、交付台真实页面；
2. 以 Axe 扫描组件展厅、书架、编辑器和交付台，阻止 `critical` / `serious` 级 WCAG 2 A、AA 与 2.2 AA 回归；
3. 静态解析三主题令牌，冻结 10 组正文、次级文字、品牌、状态和焦点对比组合；阻止关键字体低于 12px；
4. 验收模态框/抽屉焦点归还、Esc 关闭、命令面板、中文输入法组合态和 200% 等效回流；
5. 验收触控密度 44px 目标尺寸，以及 1440、1280、1024、430、390、360 六档宣纸/夜间矩阵；
6. 验收 PWA 430、390、360 窄屏无页面级横向溢出；
7. 建立 20 万字稿件打开、滚动和切换到短场景的有界性能门；
8. 将上述门接入 `npm run check`，并归档新增页面准入规范。

## 修复记录

- 宣纸主题次级文字在画布和下沉表面上的对比度提高到至少 4.85:1；品牌眉题使用更深的朱砂语义色；
- 示例树补齐 `tree` / `treeitem` 父子语义；
- 编辑器树计数、页脚和交付状态移除低对比硬编码颜色；
- 720px（1440px 的 200% 等效宽度）顶栏收起次要工具，消除图标命中区重叠；
- 既有样式中的 8～11px 字体统一提升到 12px 下限。

## 完成定义

- `npm run check` 包含 UI 静态门、UI 质量门、类型、单元/集成、生产构建和浏览器级测试；
- 视觉基线在未更新快照时稳定复跑；
- 代表页面无严重或致命 Axe 发现；
- 六档视口的宣纸/夜间主题及三档 PWA 窄屏无非设计意图横向溢出；
- 触控目标、焦点归还、IME 组合态、200% 回流和 20 万字旅程通过；
- Web、PWA、Tauri/Rust 版本统一为 2.1.0。

## 外部门

- 当前宿主为 Apple Silicon macOS；Windows x64 真实 Chrome、MSI/NSIS 安装与系统缩放必须在 Windows 主机执行；
- in-app Browser 可核验 PWA 页面结构与 1280px 运行态，但本地 HTTP、无触控浏览器不会满足 HTTPS、Service Worker 接管和真机触控探针；
- 360/390/430 自动视口结果不替代 iOS/Android 真机的中文输入法、离线重开、弱网保存和安装更新证据；
- 真实作者周期、正式签名、公证和公开分发状态保持 NO-GO。
