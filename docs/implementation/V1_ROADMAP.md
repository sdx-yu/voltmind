# V1 分阶段执行路线

基线：[码字软件线上调研与产品方案](../../码字软件线上调研与产品方案.md) · [里程碑与验收计划](../../归档/2026-08-26/笔不怠里程碑与验收计划_v1.0.md)

## 执行规则

每个阶段必须依次完成：规格冻结 → 数据迁移与兼容 → 服务端规则 → 可见工作流 → 自动化测试 → 真实浏览器验收 → 桌面构建 → 报告归档。工程门通过后自动进入下一阶段；遇到必须依赖账号、云端、签名证书或真实用户的门禁时，记录为外部门，不把模拟结果写成通过，并切换到下一个可独立闭环的阶段。

## 阶段拆分

| 阶段 | 对应原始调研 | 核心交付 | 进入条件 | 状态 |
|---|---|---|---|---|
| V1-A 剧情控制层 | Plot Grid、双时间线、伏笔生命周期 | 双时间轴、伏笔证据链、交付/AI 联动 | MVP/RC1 通过 | 已完成（0.3.0） |
| V1-B 视角知识层 | 角色知识范围与 POV 泄密检查 | 知识事实、角色知情起点、带证据泄密风险 | V1-A 工程门通过 | 已完成（0.4.0） |
| V1-C 系列正典层 | 系列共享正典、风格样本库 | 跨作品共享/覆盖、风格样本的可解释引用 | V1-B 工程门通过 | 已完成（0.5.0） |
| V1-D 交付体验层 | 朗读、平台交付模板 | 本地朗读、可版本化渠道规则与关闭开关 | V1-C 工程门通过 | 已完成（0.6.0） |
| V1-E 来源证明层 | 创作过程回放、来源导出 | 人写/AI 候选/作者改写来源链与可验证导出 | V1-D 工程门通过 | 已完成（0.7.0） |
| V1-S 同步工程门 | 多端加密同步、移动端收集/审阅 | 协议 spike、密钥恢复、冲突模型、真实双设备验证 | V1-E 工程门通过 | 规格冻结（0.8.0，外部门分离） |

## 阶段终止条件

- 数据兼容或恢复门不通过；
- 规则只能给出无证据结论；
- 核心工作流不能用真实界面完成；
- 自动化或桌面门失败且未修复；
- 需要外部授权却没有明确授权。

单一阶段终止不停止整条路线：记录原因后，转向下一个不受同一条件阻塞的阶段。
