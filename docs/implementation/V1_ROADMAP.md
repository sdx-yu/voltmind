# V1 分阶段执行路线

基线：[码字软件线上调研与产品方案](../../码字软件线上调研与产品方案.md) · [里程碑与验收计划](../../归档/2026-08-26/笔不怠里程碑与验收计划_v1.0.md)

## 执行规则

每个阶段必须依次完成：规格冻结 → 数据迁移与兼容 → 服务端规则 → 可见工作流 → 自动化测试 → 真实浏览器验收 → 桌面构建 → 报告归档。工程门通过后自动进入下一阶段；遇到必须依赖账号、云端、签名证书或真实用户的门禁时，记录为外部门，不把模拟结果写成通过，并切换到下一个可独立闭环的阶段。

## 阶段终止条件

- 数据兼容或恢复门不通过；
- 规则只能给出无证据结论；
- 核心工作流不能用真实界面完成；
- 自动化或桌面门失败且未修复；
- 需要外部授权却没有明确授权。

单一阶段终止不停止整条路线：记录原因后，转向下一个不受同一条件阻塞的阶段。
