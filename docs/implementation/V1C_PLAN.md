# V1-C 系列共享正典与风格样本库（0.5.0）

## 目标

让同一系列的多部作品共享不应重复维护的世界事实，同时允许单部作品显式覆盖；让作者提供的风格样本成为可见、可关闭、可追溯的 AI 上下文，而不是后台偷偷“学习文风”。

## 数据语义

- 一个项目在当前版本最多属于一个系列；移出系列不删除项目或系列正典；
- 系列正典保存人物、地点、物品、规则、事件的共享基线；
- 项目覆盖必须单独存储并显示“系列基线 → 本书覆盖”，不得直接改写共享基线；
- 风格样本可属于单项目或系列，包含标题、原文、使用指导、隐私级别和启用状态；
- AI 上下文只读取当前项目可见且启用的样本，逐项显示来源、原因和 token；
- 系列正典与样本全部进入离线备份，移除/覆盖均保留操作日志。

## 实施步骤

1. migration v5：系列、项目成员、共享正典、项目覆盖、风格样本；
2. API：系列建立/加入/移出、共享项 CRUD、覆盖 CRUD、样本 CRUD/启停；
3. 正典库增加“系列共享”入口，区分共享基线和本书覆盖；
4. AI 上下文加入启用的项目/系列样本，并限制总样本文本预算；
5. 备份恢复、跨系列隔离、项目移出不丢稿和旧备份兼容；
6. 自动化、真实浏览器、桌面发布门和验收归档。

## 验收主流程

创建系列 → 将两部作品加入 → 在作品 A 建立共享地点 → 作品 B 可见 → 作品 B 建立本书覆盖而不改变 A → 建立系列风格样本并启用 → 两部作品 AI 上下文可见 → 在 B 禁用后仅 B 不再读取 → 备份恢复后关系、覆盖和样本一致。

## 明确不做

- 多账户共享、实时协作与云端同步；
- 自动从正文抽取并直接写入系列正典；
- 模仿在世作者或未经作者授权的样本抓取；
- 无上限把整本参考书发送给模型。
