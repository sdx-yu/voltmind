# `bbd-research-v1` 最小披露研究协议

状态：R1-A 1.4.0 冻结。

## 同意

`r1-consent-v1` 文本固定并计算 SHA-256。作者必须逐项确认：有权作出参与决定、稿件权利、默认本机保存、主动导出才离开本机、自愿参加和可随时退出。系统生成随机 `R1-XXXXXXXXXXXX` 参与码，不收姓名、邮箱、手机号、账号或出生日期。

同意回执哈希覆盖参与码、同意版本、同意文本哈希、四项确认和同意时间。退出会级联删除当前数据库中的参与记录、任务和事件链；已有历史数据库快照仍按备份保留策略存在，已经主动交给研究负责人的副本也无法由离线应用远程撤回。

## 任务

只允许五类固定任务：

- `canon_loop`：完成场景、确认候选并推进正典；
- `fact_lookup`：回查人物、物品或时间事实；
- `restore_drill`：备份或快照恢复演练；
- `legacy_import`：导入旧稿并建立首批正典；
- `weekly_reflection`：完成本周使用回顾。

同一参与码同时只能有一个活动任务。完成或中止后记录服务端计算的耗时、目标是否达到、1–5 难度、0–480 分钟预估节省和固定问题码。没有自由文本字段，避免作者误填正文、人名或敏感反馈。

项目只用于本机生成 `SHA-256(bbd-research-v1 | participantCode | projectId)` 范围指纹。研究包不含项目 ID、书名、场景名、正文、正典、来源摘录、Prompt、模型输出、密钥、设备身份或文件路径。

## 完整性

同意、任务开始和任务结束形成严格递增的 SHA-256 事件链；事件哈希覆盖序号、固定类型、受限载荷、前序哈希和发生时间。导出包再对规范化 manifest 计算 SHA-256。校验能发现误修改或篡改，但不是数字签名，不证明参与者身份、任务真实性或研究周期。

## 外部汇总边界

导出动作不完成 R1。研究负责人仍须独立核对招募资格、同意、真实使用周期、参与者去重、退出/删除请求和跨参与者汇总。原始研究包应设置访问控制和保留期限；在没有组织数据处理流程前，笔不怠不会自动上传或集中收集。
