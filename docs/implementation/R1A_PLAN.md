# R1-A 真实验证基础设施（1.4.0）

状态：R1-A 本机工程通过（1.4.0）。R1 外部验收仍为 NO-GO；自动化、浏览器或单人自测不计入真实作者门。

## 目标

让真实作者在明确知情同意后，用真实或获授权项目记录五类验证任务，并主动导出不含稿件内容、可校验的研究证据；同时提供不含正文的支持诊断和公开发布门自检，为后续两至四周种子验证建立可信底座。

## 范围

1. migration v14：本机匿名参与、任务和不可变事件链；
2. `r1-consent-v1`：逐项确认、自愿参加、主动导出和随时退出；
3. `bbd-research-v1`：任务类型、不可逆项目范围指纹、耗时、完成情况、难度、预估节省时间和预定义问题码；
4. `bbd-support-v1`：版本、运行时、数据库完整性、快照与数量级诊断，不含标题、ID、正文、Prompt、密钥或路径；
5. 发布门看板：区分本机工程检查与真实作者、Developer ID、公证、Windows 签名和移动真机外部门；
6. 退出验证时删除本机参与码、任务和研究事件，不影响书稿。

## 不计入 R1 通过的证据

- 自动化测试、测试数据库和浏览器验收产生的夹具；
- 作者只点击导出但没有完成真实任务或真实周期；
- 单台 macOS 的 ad-hoc 包、模拟 Windows 结果或没有公证回执的构建；
- 人工改写研究包、截图、口头说明或不可复核的汇总数字。

## 本机工程退出条件

- 同意、开始、完成/中止、导出、校验、退出和诊断可从真实界面完成；
- 研究包篡改、重复活动任务、无同意写入和越界指标被阻断；
- 项目普通备份不夹带全局研究身份；数据库快照仍按既有策略保护本机记录；
- 全量回归、真实浏览器和 1.4.0 桌面包通过；
- 最终报告只声明“R1-A 基础设施通过”，R1 保持等待真实外部证据。

`npm run release:readiness` 只读检查源码版本一致性、现有 macOS 签名/公证/DMG 和 Windows 安装包是否存在，并始终把真实种子验证保留为人工外部门；它不会根据文件名或环境变量伪造公开发布 GO。
