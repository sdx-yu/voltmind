# MVP 实施计划

基线：[产品定义与 MVP 规格 v1.0](../../归档/2026-08-26/笔不怠产品定义与MVP规格_v1.0.md)

## 阶段

1. 建立本地应用骨架、SQLite migration、API 契约和自动化测试。
2. 完成项目、书稿树、编辑器、操作日志、快照、搜索、导入导出和备份。
3. 完成实体、时态状态、Mention、候选变化、正典事务和规则检查。
4. 完成 AI Provider、上下文胶囊、任务、结构化事实抽取和候选 Diff。
5. 完成交付台、设置、隐私、恢复、性能和无障碍打磨。
6. 按 FR-001～FR-020、NFR 和端到端任务验收，归档证据。

## 工程完成定义

- `npm run check` 全部通过；
- 数据迁移、事务、快照和备份有自动化覆盖；
- 核心流程通过真实浏览器交互；
- 规格追踪矩阵中没有无证据的 Must 项；
- 已知限制与商业验证项明确区分，不把未执行用户研究伪装成通过。
