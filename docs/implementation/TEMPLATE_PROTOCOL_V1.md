# `bbd-template-v1` 本地结构包协议与威胁模型

状态：V2-P 1.2.0 冻结。

## 目标

允许作者从本地文件导入可校验、可预览、可撤销的剧情结构模板，同时把第三方能力限制在一组不会触及正文、密钥、网络、任意文件和系统命令的声明式操作中。本协议不执行包内代码，也不提供发布者身份、官方认证、下载量或安全背书。

## 顶层格式

```json
{
  "format": "bbd-template-v1",
  "protocolVersion": 1,
  "manifest": {
    "packageId": "example.three-act",
    "name": "三幕结构",
    "version": "1.0.0",
    "description": "…",
    "authorLabel": "作者自述",
    "license": "CC0-1.0",
    "sourceUrl": "",
    "capabilities": ["plan.nodes.create"],
    "structureHash": "sha256"
  },
  "structure": { "nodes": [], "rules": [] },
  "packageHash": "sha256"
}
```

顶层、manifest、结构节点和规则均使用严格 Schema；未知字段被拒绝。单包最多 512 KiB、100 个结构节点和 20 条本地规则。

## 声明式结构

- 节点只允许 `chapter` 与 `scene`，正文始终为空；
- 章节必须位于书稿根目录，场景必须指向同包章节；
- 节点本地 ID 和同级标题不得重复；
- 状态只允许 `idea` 或 `planned`；
- 描述仅用于应用前预览，不会写成正文；
- 规则只允许 `minimum_scene_count` 与 `unique_titles`，服务端按固定实现解释配置，不解析或执行表达式、JavaScript、Wasm、Node 模块或系统命令。

## 内容寻址与完整性

```text
structureHash = SHA-256(canonicalJSON(structure))
packageHash   = SHA-256(canonicalJSON({ format, protocolVersion, manifest, structure }))
```

安装前必须重算两层哈希。结构资源按 `structureHash` 存储，相同内容复用；`packageId + version` 相同且 `packageHash` 相同为幂等，相同 ID/版本但内容不同为碰撞并阻断。SHA-256 只能发现导出后的修改，不是发布者数字签名。

## 能力模型

唯一允许声明的能力为：

| 能力 | 允许读取或写入 | 明确禁止 |
|---|---|---|
| `project.summary.read` | 当前显式项目的书名、简介、章节数、场景数 | 正文、正典详情、其他项目 |
| `plan.nodes.create` | 在当前项目新建空白计划章节和场景 | 覆盖、移动、删除已有节点；写正文 |
| `local.rules.run` | 对当前项目的节点数量和标题运行内置规则 | 自定义代码、网络、文件、密钥 |

安装不等于授权。每个项目、每个包、每项能力默认拒绝，作者逐项开启后才生效。正文读取、网络访问、恢复短语/API Key、任意文件系统、Node/系统命令不存在可授权入口。

## 预览、应用与撤销

1. 预览显示所有待建节点、父级、状态、空白正文、标题冲突和本地规则结果；
2. `previewHash` 同时绑定包哈希和当前书稿树。预览后书稿结构变化，旧预览失效；
3. 缺少能力时可以查看预览，但不能应用；
4. 同名章节必须由作者明确选择“加模板后缀”，不覆盖已有节点；
5. 应用在单个 SQLite 事务内创建全部节点、应用记录和来源事件；任一步失败全部回滚；
6. 整批撤销把本次创建的根节点及后代移入项目回收站，保留可恢复内容、应用历史和来源事件；
7. 停用或卸载只影响后续使用，不静默删除已创建节点或历史。

## 备份与恢复

普通项目备份保存相关包、项目授权和应用/撤销记录。恢复为新项目时节点 ID 和应用引用重新映射；包内容碰撞会中止恢复。模板包不包含正文、密钥或网络凭据。

## 明确不保证

- `authorLabel`、`sourceUrl` 和许可证都是包内自述；
- 当前没有发布者身份、代码签名、恶意内容审核、版权审查或下架通道；
- 本地目录不是在线商城，不显示下载量、评分、推荐或“官方认证”；
- 未来若允许远程代码或新能力，必须使用新协议版本和独立安全评审，不能扩大 v1 的语义。
