# UI-B 壳层与信息架构（1.8.0）

基线：[UI 统一规划与设计方案 v1.0](UI_SYSTEM_PLAN_V1.md)、[UI-A 设计基础](UIA_PLAN.md)

状态：本机工程与真实浏览器验收通过（2026-08-28）。

## 目标

在不改变业务数据协议的前提下，把长期累积的功能入口重新组织成稳定任务模型；减少书架与交付台的动作噪声，并让高频功能能通过键盘快速抵达。

## 信息架构

项目一级模式固定为五个：

1. **写作**：正文、书稿树、检查器、本地朗读与安静冲刺；
2. **规划**：情节双时间轴、伏笔、视觉故事板与结构模板；
3. **正典**：人物、地点、物品、关系及系列正典；
4. **修订**：连续性候选、角色化审阅与创作来源；
5. **交付**：渠道规则检查、范围选择、导出与完整备份。

加密接力属于全局工具，不占一级模式。搜索、设置、回收站、帮助和返回书架进入全局工具区或更多菜单。

## 已完成范围

- 五模式项目导航，子工具保持所属模式高亮；
- 上下文工具与全局工具分组，交付台移除跨模式入口堆叠；
- `Cmd/Ctrl+1～5` 切换模式，`Cmd/Ctrl+K` 打开项目或书架命令面板；
- 命令面板支持筛选、上下键、回车、Esc 和焦点归还；
- 书架只显示搜索、导入、新故事和更多操作；
- 新故事提供“直接开写”和“从结构起步”两条路径；
- 左右面板支持鼠标拖动及键盘调整，开关、宽度与最后模式保存在本机；
- Tauri 原生菜单同步五模式和命令面板；
- UI 静态门检查五模式、命令面板、宽度持久化、书架降噪及交付台边界。

## 边界与下一阶段

UI-B 只重构壳层、入口和导航状态，不重写各业务页面。`src/styles.css` 的存量样式仍按 UI-A 基线冻结。下一阶段 **UI-C** 将建立页面模板，并优先迁移写作台、规划台、正典台、修订台和交付台的页头、工具栏、容器、状态与响应式布局。
