# UI-D 长尾工作流统一（2.0.0）

基线：[UI 统一规划与设计方案 v1.0](UI_SYSTEM_PLAN_V1.md)、[UI-C 页面模板与核心工作台](UIC_PLAN.md)

状态：本机工程与真实浏览器验收通过（2026-08-28）。

## 目标

把修订、交付、审阅接力、来源、设备接力、恢复和真实验证等低频但高风险页面统一为可预测的 Workflow 体验，不改变其数据、权限或协议语义。

## Workflow 契约

- 页面以统一 `PageHeader` 说明目标、边界、返回动作和当前状态；
- 两步以上的流程使用 `WorkflowSteps`，用 `aria-current="step"` 标明当前位置；
- 需要概览的数据使用 `MetricStrip`，保持可访问命名和统一状态色；
- 内容卡、通知、字段与动作沿用设计基础语义变量，不新增裸颜色；
- 模板负责最大内容宽度、纵向滚动、窄屏堆叠、触控命中区与减弱动画；
- 作者界面使用任务语言，研发阶段号只保留在协议、文件名和工程文档中。

## 已完成范围

1. 修订台和交付台：统一目标说明、状态摘要与检查/导出步骤；
2. 角色审阅和创作来源：统一返回路径、身份切换、权限边界与来源指标；
3. 设备接力和数据库恢复：明确本地文件边界、一次性短语、检查与确认步骤；
4. 真实作者验证、受控研究台与两周波次：保留 NO-GO 和人工复核边界，移除面向用户的研发代号；
5. 为 9 个 Workflow 页面建立静态门，补充步骤和指标组件回归；
6. 三主题、三密度及 1023/759 窄屏规则延伸到 Workflow 页面。
