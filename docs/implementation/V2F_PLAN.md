# V2-F 安静冲刺与小组目标（1.1.0）

状态：本机工程通过（1.1.0）。对应原始调研 V2 的第二项“安静自习室、拼字冲刺和小组目标”。已完成本地可信计时、可验证结果卡与离线小组板；没有账号和中继时，不伪造在线房间、成员身份或实时在线人数。验收证据见[归档报告](../../归档/2026-08-27/笔不怠V2-F安静冲刺与小组目标验收报告_v1.1.0.md)。

## 目标

作者可从当前场景或项目目标发起 10–120 分钟冲刺，在安静模式中看到剩余时间、净新增和轻量提醒；结束后形成基于版本与时间边界的结果卡。多人可手动交换结果卡，在离线小组板中合并目标进度，但参与者名称只作为自填标签。

## 实施范围

1. migration v11：冲刺会话、不可变采样点、暂停/恢复事件、结果卡和离线小组板；
2. 以场景版本和时间边界计算净新增，不把按键次数、粘贴或撤销误算为多份产出；
3. 安静模式：计时、目标、当前净新增、暂停/提前结束、系统睡眠后的明确对账，不自动提交正文；
4. 冻结 `bbd-sprint-v1`：结果摘要、项目/场景脱敏指纹、时间、净新增、事件哈希链与可选笔名，不包含正文；
5. 离线小组目标：导入结果卡、按不可变 ID 幂等合并、同 ID 异载荷阻断、参与者与日/周目标汇总；
6. 本地通知、键盘可达、减弱动画、备份恢复、移动只读结果与桌面发布；
7. 自动化、真实浏览器、计时/睡眠故障注入和文档归档。

## 验收门

- 正常写作、粘贴、撤销、切场景、暂停和系统睡眠后，净新增与实际版本差一致；
- 计时器不依赖单一递减 interval，恢复后按可信墙钟对账，异常时显式提示而非伪造连续在线；
- 结果卡默认不含书名、正文、正典、设备 ID、提示词或密钥；篡改与 ID 碰撞失败；
- 同一结果卡重复/乱序导入不重复累计，小组板可从普通备份恢复；
- 安静模式不会阻止自动保存、版本记录、紧急退出或无障碍操作；
- 1.0.0 审阅、移动、同步、来源和备份全量回归通过。

## 明确不做

- 在线房间、真实在线人数、聊天室、摄像头/麦克风、好友关系或排行榜；
- 认证成员身份、防作弊承诺、公开社区、举报/封禁和内容审核；
- 后台常驻云计时、推送 SLA、跨设备自动续接或付费小组订阅。

## 外部门

- 真实账号、中继、在线 presence、邀请撤销与反滥用；
- 多人真实小组四周留存、冲刺完成率、社交压力和付费意愿验证；
- macOS/Windows 睡眠、系统时钟跳变与通知权限真机矩阵。
