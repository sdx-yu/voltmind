# RC1 桌面交付与恢复加固计划

基线：MVP v1.0 本机功能验收；阶段目标来自 G4 第 14～16 周发布门禁。

## 范围

1. **桌面壳**：以 Tauri 2 封装现有 React 界面，并把本地 Node/SQLite 服务作为自包含 sidecar；数据改存系统应用数据目录。
2. **损坏库救援**：主库无法打开或完整性检查失败时进入专用救援模式；只允许查看有效快照、恢复到主库、保留损坏原件。
3. **发布治理**：生成 CycloneDX SBOM、第三方许可证清单、隐私/备份/故障反馈说明，并提供可重复的构建命令。
4. **验收**：自动化覆盖救援事务；真实浏览器覆盖救援 UI；构建并启动 macOS 未签名 `.app`，验证 sidecar、持久化、退出和重启。

## 非本机可完成项

- Apple Developer ID 签名、公证和正式自动更新密钥；
- Windows 11 安装包、Credential Manager 与微软拼音/搜狗输入法矩阵；
- 真实种子作者四周留存和付费意愿。

这些项目继续作为公开发布 NO-GO 门禁，不以模拟结果替代。

## 退出标准

- `npm run check`、救援测试、安全审计、SBOM/许可证生成全部通过；
- macOS `.app` 能在无开发服务器的条件下启动并访问自包含 sidecar；
- 人为损坏主库后能从校验通过的快照恢复，损坏文件有留存且新库完整性为 `ok`；
- RC1 验收报告和构建物哈希归档。
