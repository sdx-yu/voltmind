# 笔不怠发布物料

- `bom.cdx.json`：CycloneDX 1.6 生产依赖 SBOM；
- `third-party-licenses.json`：生产依赖许可证和来源清单；
- `笔不怠_0.3.0_aarch64.dmg`：V1-A macOS Apple Silicon 安装镜像；
- `笔不怠_0.3.0_aarch64.app.zip`：V1-A 应用压缩包；
- `笔不怠_0.4.0_aarch64.dmg`：V1-B macOS Apple Silicon 安装镜像；
- `笔不怠_0.4.0_aarch64.app.zip`：V1-B 应用压缩包；
- `笔不怠_0.5.0_aarch64.dmg`：V1-C macOS Apple Silicon 安装镜像；
- `笔不怠_0.5.0_aarch64.app.zip`：V1-C 应用压缩包；
- `笔不怠_0.6.0_aarch64.dmg`：V1-D macOS Apple Silicon 安装镜像；
- `笔不怠_0.6.0_aarch64.app.zip`：V1-D 应用压缩包；
- `笔不怠_0.7.0_aarch64.dmg`：V1-E macOS Apple Silicon 安装镜像；
- `笔不怠_0.7.0_aarch64.app.zip`：V1-E 应用压缩包；
- `SHA256SUMS`：各版本应用包和上述物料的 SHA-256 校验。

本目录不包含签名私钥或 API Key。macOS 内测包当前仅为 ad-hoc 签名，正式对外分发前仍需 Developer ID 签名与 Apple 公证。
