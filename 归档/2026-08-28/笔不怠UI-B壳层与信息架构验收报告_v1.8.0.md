- 五模式项目壳：写作、规划、正典、修订、交付；

- 面板开关、宽度和最后模式持久化；

- 新增覆盖：五模式导航、命令面板跳转、键盘面板调宽、书架核心动作、两条创建路径和书架项目跳转。

## 真实浏览器证据

在本地 Chromium 对真实服务与已有项目数据执行：

1. 书架仅显示搜索、导入、新故事、更多操作；
2. 新故事可在“直接开写”和“从结构起步”间切换，提交文案随路径变化；
3. `Cmd/Ctrl+K` 打开书架命令并列出已有项目与恢复/研究入口；
4. 项目壳展示五个一级模式；规划显示视觉故事板与结构模板，修订显示角色化审阅与创作来源；
5. 项目命令面板按“交付”筛选后仅保留交付台命令，并正确跳转；
6. 860×760 视口下页面宽度等于视口宽度，无横向溢出，五个导航按钮均可访问；
7. 浏览器控制台错误与警告均为 0。

## 边界
