## 本阶段修复

- 将既有 8～11px 关键字体统一提升到 12px；
- 加深宣纸主题次级文字和品牌眉题语义色，并把画布、纸张、下沉表面的组合加入静态门；
- 补齐示例树的 ARIA 父子语义；
- 修复编辑器树计数、页脚和交付状态的低对比硬编码色；
- 修复 720px 下项目顶栏工具与主导航命中区重叠；
- 分离 Vitest 与 Playwright 的测试收集范围，浏览器门正式接入 `npm run check`。
