# 笔不怠正文正典识别真值修复验收报告 v2.3.6

## 结论

2.3.6 已完成源码验收、真实界面交互检查、macOS Apple Silicon 桌面构建和安装包完整性校验，可用于本机内测。检查器现在明确区分“正文识别到正典”与“识别后发现连续性冲突”，不再把没有冲突误表现为没有识别到人物。

公开发布仍为 NO-GO：当前安装包采用 ad-hoc 签名，尚未配置 Apple Developer ID 签名与公证。

## 本次范围

- 增加独立的“正文正典识别”结果，展示匹配名称、别名、出现次数和正典类型；
- 连续性检查改为单独的冲突层，明确说明“识别成功不等于存在冲突”；
- 正文自动保存后，正典识别和连续性结果自动刷新；
- 同名正典档案同时命中时显示歧义提示，不擅自删除或合并作者数据；
- 已配置的正典别名不再被专名近似规则误报为错别字；
- 空匹配状态说明至少 2 个字的名称或别名精确匹配边界。

## 产品与交互验收

- 预设人物通过正典名称和别名均可被正文识别；
- 人物在正文中出现多次时，出现次数正确汇总；
- 存在两份同名档案时只显示一个名称，并明确提示同名档案数量；
- 从正文删除人物名称并等待自动保存后，界面自动切换为未匹配状态；
- 重新输入名称或别名并自动保存后，识别结果自动恢复；
- 已配置别名不会再产生专名错字提示；
- 本机浏览器控制台无错误或警告。

- `npm run ui:check`：通过，原生选择器 0、裸必填字段 0；
- `npm run ui:quality`：通过，关键字号不低于 12px，3 套主题与关键对比度符合门槛；
- TypeScript 类型检查：通过；
- Vitest：50 个测试文件、201 个测试全部通过；
- Vite 生产构建：通过；
- Playwright：10 个端到端场景全部通过；
- APP 深度严格签名结构校验：通过；
- DMG `hdiutil verify`：通过；
- APP ZIP 完整解压测试：通过；
- App / 构建版本：均为 2.3.6；主程序与本地服务均为 Apple Silicon `arm64`。
