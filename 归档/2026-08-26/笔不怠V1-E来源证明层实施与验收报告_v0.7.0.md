# 笔不怠 V1-E 来源证明层实施与验收报告 v0.7.0

日期：2026-08-26  
结论：工程验收通过，可作为 Apple Silicon 内测版继续使用；法律证据效力、平台原创认证、正式签名公证与跨系统矩阵仍是外部门。

## 1. 本阶段范围

V1-E 把原始调研中的“码字过程回放”和“原创留痕”落成可解释、可校验但默认不泄露正文的本地闭环：

- 项目时间线记录人工编辑、AI 候选生成/失败、作者接受/拒绝/撤销、AI 后人工修订、导入、恢复、拆分合并、批量替换和事实候选；
- 场景版本携带父版本、来源标签和关联 AI 任务，可按人工、AI、导入/恢复筛选并与父版本做 Diff；
- `bbd-provenance-v1` JSON 包含顺序、动作、关系、内容哈希、事件链和清单哈希，可在“来源”页本地复验；
- HTML 报告提供可阅读时间线；正文摘录必须显式勾选且单版本最多 500 字；
- AI 脱敏任务元数据、版本关系、来源事件链和导出记录进入 `bbd-backup-v2`，恢复后保持事件哈希和任务关系；
- 报告明确不等同于版权确权、司法证据、可信时间戳或平台原创认证。

明确没有实现逐键录制、后台监控、区块链、签章、默认正文导出或 Prompt/API Key 留存。

## 2. 数据与完整性设计

SQLite schema 升至 v7，升级前自动生成 `pre-migration-vN-to-v7` 备份。新增：

- `revisions.provenance_label` / `source_task_id`：区分人工、AI 接受、AI 后人工修订、导入、恢复和合并；
- `provenance_events`：按项目形成 SHA-256 前向事件链；哈希只覆盖稳定动作字段，不依赖恢复时会变化的数据库 ID；
- `provenance_exports`：记录格式、清单哈希、事件数和是否包含正文摘录；
- v7 兼容投影：从旧 revisions、AI 任务、事实候选、导入原件和替换批次生成不超出既有证据的事件。

AI 任务只持久化任务类型、Prompt 版本、模型、上下文哈希、输出哈希、token、状态和时间，不保存 Prompt 或输出全文。证明包清单再做一次隐私收窄，默认只含元数据和哈希。

恢复备份时先验证原事件链，再映射项目、节点、版本和任务 ID；因为事件哈希不依赖这些内部 ID，恢复后的哈希序列和项目指纹保持一致。坏链会中止整个恢复并清理新建项目。

## 3. 可见工作流

新增顶层“来源”工作台：

1. 摘要显示人工决策、AI 参与、系统动作和当前链头；
2. 时间线可按场景与人工/AI/系统筛选，区分“作者接受 AI 候选”和“AI 内容写入版本”；
3. 版本事件可定位场景并查看与父版本的差异、来源和完整内容哈希；
4. JSON/HTML 导出前明确显示隐私边界，正文摘录默认关闭；
5. 用户可选取已有 JSON 包在本机校验清单和事件链；
6. 最近导出列表显示事件数量、正文选项和清单哈希前缀。

编辑器把 AI 接受的 task ID 写入下一次不可变版本；之后的普通保存沿祖先链识别为“AI 后人工修订”，不会退化为“纯人工”。

## 4. 自动化验收

`npm run check` 最终结果：

- TypeScript 前后端类型检查通过；
- 15 个测试文件、51 项测试全部通过；
- Vite 生产构建通过，2,139 个模块完成转换；
- v2/v3/v4/v5/v6 到 v7 迁移、迁移前备份和旧版本兼容投影通过；
- AI task → 作者决定 → AI 版本 → AI 后人工修订关系测试通过；
- 默认证明包不含测试 Prompt 和 AI 输出全文，显式正文选项与 500 字上限通过；
- 清单与事件篡改检测失败路径通过；
- 备份恢复后事件哈希序列、AI 版本任务引用和可验证链保持一致；
- 来源筛选、父版本 Diff 和显式正文导出组件流程通过；
- 20 万字符性能用例及 MVP、RC1、V1-A～V1-D 回归继续通过。

生产依赖审计为 0 个已知漏洞；CycloneDX 1.6 SBOM 含 168 个组件，许可证清单覆盖 177 个运行时包。

## 5. 真实界面验收

使用独立本地数据目录建立“V1-E 来源验收”项目，完成以下闭环：

1. 人工写入“雨落在旧港，林照停在灯下。”并等待自动保存；
2. 演示模型生成 4 段候选，作者接受全部候选；
3. 来源页显示人工编辑、AI 候选生成、作者接受与 AI 内容写入版本；
4. 版本回放正确显示 AI 版本与父版本的新增差异；
5. 作者回到正文继续修改后，时间线显示“AI 后人工修订”；
6. JSON 导出默认复选框未勾选，最近导出明确显示“不含正文”；
7. 来源页在 1280×720 视口无横向溢出，导航、时间线、侧栏和弹窗均可操作。

真实验收发现“作者接受”和“AI 内容写入版本”原先使用相同文案，虽数据语义正确但阅读上易混淆；已按事件元数据和版本关系拆分显示，并重新通过类型与组件测试。

## 7. 未关闭的外部门

- Apple Developer ID 签名和公证尚未执行，当前包只适合内测；
- Windows 11、多个 macOS 大版本、输入法和缩放矩阵仍需真机；
- 本地哈希链不能自行证明真实身份、可信时间或法律权利；
- 第三方可信时间戳、签章或平台原创认证必须由相应机构提供；
- 种子作者四周留存、来源报告实际价值和付费意愿尚未验证；
- 50 万字全书检查的后台取消仍属于发布前性能门。
