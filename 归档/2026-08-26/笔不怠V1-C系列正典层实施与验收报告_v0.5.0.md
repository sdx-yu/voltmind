# 笔不怠 V1-C 系列正典层实施与验收报告 v0.5.0

日期：2026-08-26  
版本：0.5.0  
结论：工程与本机内测 GO；公开发布仍为 NO-GO。

## 1. 本阶段目标

V1-C 将多部作品共同维护的世界事实提升为“系列共享基线”，同时允许每本书建立独立覆盖；将作者主动提供的风格样本做成可见、可关闭、可追溯且受预算限制的 AI 上下文。

## 2. 已完成范围

### 2.1 数据与隔离

- SQLite schema 升至 v5，升级前自动创建原数据库备份；
- 新增系列、系列成员、共享正典、项目覆盖、风格样本和项目样本偏好；
- 一个项目最多属于一个系列；移出系列不删除书稿、系列正典或该项目已有覆盖；
- 本书覆盖独立存储，界面固定显示“系列基线 → 本书覆盖”，不会写回基线；
- 系列样本的默认启用与单本书偏好分离，作品 B 的停用不会改变作品 A；
- 系列建立、成员加入/移出、共享项、覆盖、样本与偏好变化均写入操作日志。

### 2.2 服务端与界面

- 完成系列 CRUD、加入/移出、共享正典 CRUD、覆盖 CRUD、样本 CRUD/启停 API；
- 正典库新增“系列共享”入口，可创建系列、加入已有系列、添加其他作品；
- 共享正典支持人物、地点、物品、事件，并清晰展示共享来源和本书覆盖；
- 风格样本支持系列/单书范围、原文、使用指导、隐私级别、来源与启用状态；
- 界面只把尚未归属其他系列的作品列为可加入成员，服务端仍执行最终唯一性校验。

### 2.3 AI 与备份

- AI 上下文只读取当前项目可见且有效启用的风格样本；
- 每个样本显示系列/项目来源、入选原因、隐私级别和估算 token；
- 风格样本文本总预算限制为 1200 token，超过部分确定性截断；
- `local_private` 样本可在本地查看，但默认不勾选且任务执行端再次拒绝发送；
- 项目离线备份包含当前项目的系列快照、共享正典、本书覆盖、系列/单书样本与本书偏好；
- 恢复时建立独立“原系列名（恢复）”系列，避免把恢复数据静默并入现存系列；其他成员项目不会被凭空复制。

### 3.2 真实浏览器主流程

使用本地真实界面创建 `V1-C 系列验收 A` 与 `V1-C 系列验收 B`，完成：

1. A 创建“雾港纪事”，把 B 加入，成员数显示为 2；
2. A 创建共享地点“旧雾港”，B 无复制操作即可看到相同基线；
3. B 创建“新港区”本书覆盖，界面仍保留“旧雾港”系列基线；
4. 切回 A 后没有出现 B 的覆盖，隔离通过；
5. A 创建系列样本“雾港短句节奏”，AI 胶囊显示“当前项目所属系列的已启用样本 · 47 token”；
6. B 单独停用后，其 AI 胶囊从 2 项约 47 token 降为 1 项 0 token；
7. A 仍显示样本已启用；
8. 浏览器控制台 error 为 0。

两个验收项目保留在开发书架中，便于后续回看，不执行不可恢复清理。

## 5. 已知边界与发布判断

- 单项目备份恢复的是“当前项目可见的系列快照”，不会自动重建其他系列成员项目；这是防止误复制和误合并的明确边界；
- 本阶段不包含多账户共享、实时协作、云端同步和自动抓取文风；
- macOS 产物仍为 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证；
- 真实种子作者验证尚未完成，因此对外公开发布保持 NO-GO。
