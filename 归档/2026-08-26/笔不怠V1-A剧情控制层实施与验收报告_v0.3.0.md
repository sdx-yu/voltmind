# 笔不怠 V1-A 剧情控制层实施与验收报告（0.3.0）

验收日期：2026-08-26  
产品 slogan：**笔耕不怠，写尽所思。**

## 1. 阶段选择

依据已归档调研，对 V1 候选按差异化价值、当前技术承接度、外部依赖和可验收性复核：

| 候选 | 差异化 | 当前承接度 | 外部依赖 | 本阶段结论 |
|---|---|---|---|---|
| 单人多设备加密同步 | 高 | 中 | 云端、账户、密钥恢复、真实多设备 | 暂缓，不能只在单机上伪验收 |
| Plot Grid 与叙述/故事双时间线 | 高 | 高 | 无 | 选择 |
| 伏笔建立—强化—误导—回收 | 高 | 高 | 无 | 选择，与双时间线组成垂直切片 |
| POV 泄密检查 | 中高 | 中 | 角色知识模型与语料 | 后续 |

最终将 0.3.0 定义为 V1-A“剧情控制层”：同一份场景数据提供叙述/故事双时间轴，伏笔成为带场景证据的生命周期，并联动交付提醒和 AI 上下文。

## 2. 交付结果

- slogan 已统一进入书架首屏、页脚、HTML 标题/描述、README 和桌面应用描述；
- 剧情台已开放叙述顺序、故事时间、伏笔看板三个视图；
- 故事时间按 `storyTime` 排序，未定时间明确置后且不做猜测；
- SQLite schema migration 升至 v3，升级前生成 `v2 → v3` 数据库备份；
- 伏笔支持建立、强化、误导、回收及回收后重新强化；每个事件可保留场景、正文证据和作者备注；
- 服务端验证状态跳转与场景归属，拒绝非法或跨项目引用；
- 未回收伏笔进入交付建议，但不阻断 TXT、Markdown、DOCX 或完整备份；
- 未回收伏笔进入可解释 AI 上下文，回收后自动退出；
- `bbd-backup-v2` 在保持旧备份兼容的同时新增伏笔和完整事件链恢复；
- 版本统一升级为 0.3.0，并生成 macOS Apple Silicon `.app`、DMG、SBOM、许可证清单和 SHA-256。

## 6. 结论与限制

V1-A 本机工程验收结论：**GO，可进入内部 dogfood。**

公开分发仍为 **NO-GO**：当前 macOS 包为 ad-hoc 签名，尚未 Developer ID 签名和 Apple 公证；真实种子作者验证尚未完成；Windows、跨平台中文输入与多设备环境不在本次验收范围。

下一阶段建议在真实作者使用 V1-A 后，于“POV 角色知识/泄密检查”和“加密同步协议 spike”之间按反馈选择；不建议在没有使用数据前直接扩展为复杂自由因果图。
