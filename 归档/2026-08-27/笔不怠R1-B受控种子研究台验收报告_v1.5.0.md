# 笔不怠 R1-B 受控种子研究台验收报告 v1.5.0

验收日期：2026-08-27（Asia/Singapore）

基线提交：`096fc04`（R1-A）

结论：**R1-B 执行台本机工程通过；真实种子验证与公开发布 NO-GO。**

## 1. 本阶段交付

- schema v15：受控参与者、连续提交摘要、不可逆删除回执；v14 升级前自动创建完整数据库备份；
- `bbd-research-v1` 增加同意、任务、事件与声明进度的语义一致性校验；
- `r1b-cohort-v1`：参与码协议域哈希、同意回执、首次证据类别与固定分层、事件链严格前缀延续；
- `external_attested` 的目标作者、独立参与、稿件权利、真实周期四项负责人声明；`engineering_fixture` 永不计入门禁；
- UTC 自然周与跨度双条件：两周为 ≥2 周且 ≥8 天，四周为 ≥4 周且 ≥22 天，跨周核心闭环为两周资格且 ≥2 次成功闭环；
- 5 名两周、3 名四周、3 名核心闭环、0 数据丢失的试点数值门；所有数值仍要求人工复核且 R1 固定 NO-GO；
- 1–365 天保留、到期清除、退出删除、删除后阻止误重收；
- `.bbd-cohort` 聚合导出，不含参与码原文、原始包、标题、正文、项目/任务 ID、Prompt、密钥或路径；
- 研究负责人工作台、桌面/390px 响应式界面、用户指南、协议、隐私说明与 ADR-010。

## 2. 安全与证据边界

负责人数据库只保留不可逆参与者哈希、固定布尔声明、保留期限、包/事件哈希和有界统计。原始研究包、招募记录与同意材料由负责人在产品外访问控制。删除只影响当前数据库；历史 SQLite 快照和产品外副本必须按同意另行处理。

匿名码与人工声明不构成身份认证。自动化、浏览器夹具、开发者自测、相同链重导入、已过期或已删除记录均不计为真实作者。试点门小于原调研 G5 的 20 人/12 人四周商业门，不能替代商业验证。

## 6. 未通过与下一阶段

当前真实外部样本为 **0**，没有声称两周/四周留存、身份、因果效果、付费意愿或研究结论。当前 macOS 包为 ad-hoc 签名，非 Developer ID 且未 Apple 公证；没有 Windows x64 签名安装包、真实中文输入法矩阵、移动真机与正式分发证据。
