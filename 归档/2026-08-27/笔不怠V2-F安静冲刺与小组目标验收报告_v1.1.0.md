## 1. 阶段目标与结论

V2-F 对应原始调研 V2 的第二项“安静自习室、拼字冲刺和小组目标”。本阶段完成本地可信冲刺、安静写作 HUD、无正文可验证成果卡和离线小组板：作者可以按当前场景或整个项目发起冲刺，系统以开始与结束的已保存版本差计算净新增；作者也可以手动交换结果卡，在本地看板汇总日/周目标，但不会把自填笔名冒充为认证成员身份。

工程验收结论为通过。最终 `npm run check` 完成 26 个测试文件、89 项测试，TypeScript 与生产构建均通过；真实浏览器完成“发起—写作—暂停—恢复—结束—成果卡—本周看板—移动只读”的主路径；macOS Apple Silicon 的 1.1.0 应用与 DMG 已构建、校验并完成本机启动冒烟。公开发布仍为 NO-GO：当前仅 ad-hoc 签名，尚无 Developer ID 签名、Apple 公证、认证身份和在线服务。

## 2. 主要交付

### 2.1 版本差净新增与可信计时

- 支持 10–120 分钟、1–50,000 字目标的场景或项目冲刺，同一项目同一时刻只允许一个活动冲刺；
- 开始时冻结所选范围的场景版本与字数，结束时读取已保存版本，净新增等于结束字数减开始字数；粘贴、撤销和重复按键不会被额外计数；
- 编辑器结束冲刺前先完成待保存内容的落盘，避免最后一次输入遗漏；
- 计时基于墙钟和不可变事件，不依赖单一递减 interval；暂停时间不计入活动时长；
- 页面隐藏或系统睡眠形成未知间隔时，在最后可确认时间点保守暂停并要求显式恢复；墙钟倒退同样暂停并记录时钟异常，不伪造连续在线；
- 本地通知只在作者主动授权后使用，到时提醒不会自动结束冲刺或提交正文。

### 2.2 安静模式与无障碍

- 写作视图显示紧凑 HUD：剩余时间、净新增、目标、暂停/恢复、结束和取消；
- 完整工作台提供发起参数、活动采样、异常说明、历史成果卡和小组板；
- 冲刺不阻断自动保存、版本记录、紧急退出或既有菜单；
- 控件保持键盘可达；全局尊重 `prefers-reduced-motion`，移动端保留只读结果而不暴露正文。

### 2.3 `bbd-sprint-v1` 成果卡协议

- 结果卡只包含协议版本、不可变卡 ID、脱敏范围指纹、目标、净新增、活动时长、时间边界、事件链摘要和可选自填笔名；
- 不包含书名、项目 ID、场景 ID、正文、正典、设备 ID、提示词、密钥或通知权限；
- 开始、采样、暂停、恢复、结束等事件形成 SHA-256 哈希链；导入时校验事件数、链头、事件时间、卡哈希与载荷结构；
- 相同卡重复或乱序导入幂等，同一 ID 的不同载荷被明确阻断；
- 哈希用于完整性与误修改检测，不是认证签名，也不构成参与者身份或防作弊证明。

### 2.4 离线小组目标

- 可创建日目标或周目标看板，按成果卡时间边界校验是否属于看板周期；
- 支持导入他人的 `bbd-sprint-v1` 包，也可将本机成果卡加入看板；
- 汇总净新增、冲刺次数、参与者自填标签与目标进度；重复卡不会重复累计；
- 不显示在线人数、实时 presence、排行榜或认证徽章，不提供聊天室、好友或公开社区。

### 2.5 数据、API、备份与移动端

- SQLite migration v11 新增冲刺会话、不可变采样、事件、结果卡、看板与看板卡；从 v10 升级前自动生成备份；
- API 覆盖发起、列表、暂停、恢复、异常对账、结束、取消、导出/预检成果卡和看板创建/导入/本机加入；
- 普通 `bbd-backup-v2` 保存冲刺会话、成果卡与离线看板；恢复时活动会话改为已取消，避免把停机时间伪造为连续冲刺；
- 项目清理同步删除关联冲刺数据；已删除场景的历史结果仍可从冻结采样读取；
- 移动书架缓存最近成果卡，只读显示净新增、笔名、时长与结束时间，并明确标注“不含正文”。

## 4. 真实浏览器验收

在既有本地项目“V2-R 角色审阅验收”完成如下闭环：

| 场景 | 结果 |
|---|---|

| 安静写作 | 自动进入专注写作，紧凑 HUD 初始显示 10:00 与净新增 0 |
| 真实输入与保存 | 在 Tiptap 编辑器输入“风声催他向前。”，正文从 22 字保存为 28 字，HUD 刷新为净新增 +6 |

| 结束与成果卡 | 结束前刷新编辑器保存，生成净新增 +6、匿名作者、1 分钟、4 个链式事件的成果卡 |

## 7. 已知限制与外部门

- 1.1.0 不提供账号、在线房间、真实在线人数、好友、聊天、实时排行榜或云推送 SLA；
- 自填笔名不是认证身份，SHA-256 完整性链不是数字签名，也不作防作弊承诺；
- 未执行多个真实用户跨网络、四周小组留存、社交压力、完成率和付费意愿验证；
- 系统睡眠和时钟跳变由可控故障注入覆盖，尚未完成 macOS/Windows 多版本真机矩阵；
- 通知授权路径已实现，但未覆盖所有 macOS 通知设置组合；
- 未执行本阶段新增界面的 iOS/Android 真机与新增窄屏浏览器矩阵；
- macOS 包未使用 Developer ID 签名且未 Apple 公证；Windows 构建仍未执行。

因此：本机与小范围内部试用为 GO；公开下载、商用多人服务和应用商店发布为 NO-GO。
