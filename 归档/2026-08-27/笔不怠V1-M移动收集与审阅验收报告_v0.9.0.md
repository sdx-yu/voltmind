# 笔不怠 V1-M 移动收集与审阅验收报告

- 版本：0.9.0
- 日期：2026-08-27
- 阶段结论：本机工程通过；真实手机部署、iOS/Android 真机矩阵和云中继仍为外部门
- 产品口号：笔耕不怠，写尽所思。

## 1. 阶段目标与结论

V1-M 对应原始调研中 V1 尚未闭环的“移动端灵感收集与审阅”。本阶段完成可安装 PWA、离线优先收集箱、只读审阅、不可变处理动作、普通备份恢复与 `bbd-sync-v1` 加密接力互通；移动端没有扩张为缩小版桌面编辑器，也没有用本机模拟冒充账号或真实云服务。

工程验收结论为通过。最终门禁为 22 个测试文件、72 项自动化测试全部通过，TypeScript 和生产构建通过；360/390/430px 真实浏览器流程、断服重开、联网回流、桌面主流程与 macOS 自包含应用启动通过；npm 生产/全量审计均为 0 个已知漏洞。

## 2. 主要交付

### 2.1 移动产品面

- 首页固定为“快速记录、继续阅读、待处理”三段；包含品牌口号、联网/回流/仅本机状态和安装入口；
- 支持灵感、场景想法、审阅笔记，可选项目与目标场景；所有写入先提交 IndexedDB，再尝试回流；
- 最近场景仅供阅读，显示项目、版本时间和纯人工/AI 后人工/导入/恢复/同步等来源摘要；
- 审阅笔记和认可、归档、忽略均为显式动作，不直接改正文、正典或来源链；
- 低存储时不假报成功；本地库异常提供有数据损失警告的显式重建入口。

### 2.2 PWA 与离线

- `manifest.webmanifest`、192/512 图标、移动启动 URL、standalone 展示与快捷入口；
- Service Worker 安装阶段解析生产 HTML，将入口、哈希 JS/CSS、清单和图标一次性缓存；任一核心资源失败会使新 worker 安装失败；
- 非 API GET 使用网络优先、缓存回退；API 和写请求从不进入缓存；导航失败时按当前 shell、上一 shell回退；
- 新 worker 等待用户点击“立即更新”才 `skipWaiting`；激活时保留当前与一个上一版本 shell；
- 数据与 shell 分离：升级/回滚缓存不删除 IndexedDB 收集项。

### 2.3 数据、API、备份和同步

- SQLite migration v9 新增 `mobile_inbox_items` 与 `mobile_inbox_actions`，升级前自动生成 v8→v9 备份；
- 收集项和动作使用来源设备生成的不可变 ID。同 ID 同载荷重复为幂等，同 ID 异载荷拒绝；
- 当前动作按 `created_at,id` 从追加事件折叠，重复和乱序导入确定性收敛；
- 普通 `bbd-backup-v2` 保存已归属项目的收集项和动作，恢复时重映射目标场景；未归类项不进入单项目备份；
- `bbd-sync-v1` 载荷新增可选 `mobileInbox`，0.8.0 无该字段的接力包继续可读；已归属和未归类事件通过原 AES-256-GCM 密文做并集；
- 同步预检显示移动收集项数量；移动数据不能借接力包越权写入另一项目。

- Vitest：22 个测试文件、72 项测试全部通过；
- Vite：2148 个模块成功转换，生产构建成功；
- PWA：清单/图标、首装哈希资源缓存、上一 shell、用户确认激活、API 排除均有契约测试；
- IndexedDB：20 条离线记录关闭重开保留；重复/乱序动作收敛；本机/远端并集不删本机事件；低存储不宣称成功；缓存异常可显式修复；
- API/数据库：20 条记录双次重放仍为 20 条；乱序动作投影正确；v8→v9 自动备份；
- 备份：项目移动记录、动作和场景引用恢复并重映射；

## 7. 已知限制与外部门

- 0.9.0 不提供手机可访问的 HTTPS/LAN/公网入口。PWA 标准实现和本机浏览器工程验收已完成，但真实手机访问必须在后续部署门完成；
- 未执行 iOS Safari 主屏安装、Android Chrome、厂商 WebView、软键盘、安全区、系统回收和低存储真机矩阵；
- 未部署账号、云中继、设备吊销、密钥轮换、推送、遥测或应用商店包；
- 未归类项当前按单作者模型随项目接力包做并集；未来并行多项目中继需独立收集箱流；
- macOS 包未使用 Developer ID 签名且未 Apple 公证；Windows 构建仍未执行；
- 种子作者留存、移动收集使用率和付费意愿仍须真实用户验证。
