# 笔不怠 R1-A 真实验证基础设施验收报告

- 版本：1.4.0
- 日期：2026-08-27
- 阶段结论：R1-A 本机工程通过；R1 公开发布保持 NO-GO
- 产品口号：笔耕不怠，写尽所思。

## 1. 阶段目标与结论

R1-A 不再增加新的创作功能，而是落实最初调研方案中的真实验证底座：让作者在固定知情同意后，用真实或获授权项目记录有界任务证据，主动导出不含稿件内容且可校验的研究包，并让支持与发布状态保持最小披露、不可伪造为外部通过。

本机工程验收通过。固定同意、匿名参与码、五类任务、完成/中止、事件链、研究包校验、无正文支持包、退出清除和公开 NO-GO 看板均已落地；migration v14、API、组件与备份边界通过自动化和真实浏览器闭环；macOS Apple Silicon 1.4.0 应用与 DMG 已构建并完成本机冒烟。

本结论不等于 R1 通过。自动化、浏览器夹具和单人自测不计入种子作者证据；当前没有 5 名两周/3 名四周的真实研究包，也没有 Developer ID、公证、Windows 签名包或移动真机矩阵，因此公开发布仍为 NO-GO。

## 2. 主要交付

### 2.1 固定同意与匿名身份

- `r1-consent-v1` 固定展示参与、自有稿件、默认本机、主动导出和退出边界，文本 SHA-256 可复核；
- 成年/有权决定、稿件权利、本机边界和自愿参加四项必须全部确认，服务端再次校验，不能只靠界面绕过；
- 生成随机匿名参与码，不采集姓名、邮箱、账号、设备 ID 或认证身份；
- 同意回执绑定同意版本、文本哈希、参与码和时间，后续进入研究事件链。

### 2.2 有界任务证据与可校验研究包

- 五类任务为正典闭环、事实回查、恢复演练、旧稿导入和周回顾；同一参与者最多一个活动任务；
- 只记录任务类型、开始/结束时间、完成/中止、目标是否达成、1–5 难度、0–480 分钟预估节省和七个固定问题码；
- 项目只形成不可逆范围 SHA-256，研究包不含书名、项目 ID、正文、正典、Prompt、密钥、路径或自由文本；
- `bbd-research-v1` 使用严格 Schema、不可变事件前向哈希和整包哈希；未知字段、禁用字段、篡改事件或错误链头均阻断。

### 2.3 支持诊断、退出与备份边界

- `bbd-support-v1` 只包含应用/运行时大版本、数据库完整性、schema、快照数量和对象数量级，不含标题、正文、ID、密钥或路径；
- 退出验证删除当前数据库的参与码、任务和研究事件，不影响书稿、版本或创作来源；
- 固定文案明确历史数据库快照可能仍保留旧记录，需要作者按备份策略另行管理；
- 普通项目 `bbd-backup-v2` 不夹带全局研究身份；完整 SQLite 快照仍承担灾难恢复职责。

### 2.4 发布门

- 应用内和 `npm run release:readiness` 都区分本机工程检查与外部证据；
- 版本一致、数据库迁移、回环隔离、生产静态资源、macOS 包/签名结构/DMG 可由工程检查；
- 真实作者周期、Developer ID/公证、Windows x64 签名、移动真机/弱网只能由外部证据满足；
- 检查脚本始终保留种子验证人工门，不接受文件名、自动化结果或本机夹具替代。

## 7. 已知限制与外部门

- 研究包由作者主动导出，1.4.0 不提供研究云端、账号、自动上传、跨参与者聚合或远程删除；
- 匿名参与码不是认证身份，研究负责人仍需在产品外核验参与资格、独立作者数量和真实周期；
- 预估节省时间为自报指标，不等价于因果实验；后续应结合任务成功、问题码和访谈复核；
- 退出只清除当前数据库，旧 SQLite 快照和已交付副本需分别管理；
- 当前 macOS 产物仅 ad-hoc 签名，未 Developer ID 签名或 Apple 公证；
- Windows x64 安装/卸载、代码签名、微软拼音/搜狗输入法和凭据库矩阵未执行；
- iOS/Android 安装、弱网、后台回收、更新和恢复矩阵未执行；
- 自动化与浏览器夹具为零真实样本，不能用于计算留存或商业指标。

因此：R1-A 本机工程与受控内测准备为 GO；R1 真实作者验收、公开下载和商店发布为 NO-GO。
