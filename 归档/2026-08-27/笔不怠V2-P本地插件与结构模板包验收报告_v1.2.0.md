## 1. 阶段目标与结论

V2-P 对应原始调研 V2 的第三项“插件/模板市场、可共享的剧情结构模板”。本阶段没有在缺少服务端、审核和签名体系时伪造在线市场，而是先完成安全、可验证的本地基础：作者可以预检、安装、启停、导出和卸载声明式结构模板，逐项目授权最小能力，预览将要创建的空白计划节点，以单个数据库事务应用，并把整批结果撤回项目回收站。

工程验收结论为通过。最终 `npm run check` 完成 28 个测试文件、99 项测试，TypeScript 与生产构建均通过；真实浏览器完成“零权限预览—逐项授权—规则预检—应用—书稿树核对—来源核对—整批撤销—回收站核对”的闭环；macOS Apple Silicon 的 1.2.0 应用与 DMG 已构建、校验并完成本机启动冒烟。公开发布仍为 NO-GO：当前仅 ad-hoc 签名，尚无 Developer ID 签名、Apple 公证、发布者认证、恶意包扫描和在线审核体系。

## 2. 主要交付

### 2.1 `bbd-template-v1` 声明式协议

- 包只允许严格 Schema 中的清单、章/场节点和两类固定本地规则，不执行 JavaScript、Wasm、Node、系统命令或包内脚本；
- 模板节点只有 `chapter`/`scene`，正文始终为空，状态限于构思或计划；最多 100 个节点、20 条规则，导入大小上限 512 KiB；
- 清单记录包 ID、语义版本、名称、描述、作者自述、许可证、来源网址和能力声明；作者与来源明确标注为包内自述，不代表认证身份；
- 结构与整包均按规范化 JSON 计算 SHA-256。相同 ID/版本/哈希重复安装幂等；相同 ID/版本的不同载荷按碰撞阻断；未知字段、篡改和非法父子关系拒绝；
- 内置“三幕结构起步包”提供 3 章、8 场和 2 条规则，作为可审计的本地示例。

### 2.2 最小能力与默认拒绝

- 模板最多声明 `project.summary.read`、`plan.nodes.create`、`local.rules.run` 三项能力；
- 安装后按项目默认全部拒绝，授权逐项保存、可单独撤销；不同项目之间不共享授权；
- 未授权摘要时不返回书名、简介或章节/场景数量；未授权规则时不执行规则；未授权创建时不能应用；
- 正文、网络、密钥、任意文件系统、设备身份和系统命令不存在可授权入口，模板包也不能扩展能力枚举。

### 2.3 预览、冲突、单事务应用与整批撤销

- 应用前显示项目摘要、待创建节点、父级、状态、空正文承诺、规则结果、缺失能力和同级标题冲突；
- 预览绑定当前包哈希与书稿树指纹，树发生变化后旧预览失效，必须重新确认；
- 同名章节默认取消；只有作者显式选择改名时才添加“（模板）”后缀，不覆盖既有节点或正文；
- 应用在单个 SQLite 事务中创建全部节点和记录。第二个节点故障注入证明首个节点与应用记录会共同回滚；
- 撤销把本次创建的根节点及后代软删除到项目回收站，作者仍可逐章恢复；停用或卸载包不会删除历史；
- 应用和撤销分别生成 `template_applied`、`template_reverted` 来源事件。

### 2.4 数据、API、备份与界面

- migration v12 新增内容寻址资源、包、包资源关系、项目授权、应用和模板事件六张表；从 v11 升级前自动生成备份；
- API 覆盖目录列表、导出、预检、安装、状态切换、授权、预览、应用、历史与撤销，统一由本地会话保护；
- 普通 `bbd-backup-v2` 保存项目相关的包、授权和应用/撤销记录，恢复时重映射项目与节点引用；包 ID 碰撞会中止，不静默替换；
- 交付工作台新增“结构模板”，提供本地目录、文件预检、信任说明、逐项权限、Diff、规则结果、冲突策略、应用历史和撤销；
- 来源工作台可见模板应用/撤销；书稿树与回收站呈现实际结果；界面使用原生键盘可达控件并包含窄屏重排样式。

## 7. 已知限制与外部门

- 1.2.0 不提供在线商城、账号、付费、下载量、评分、推荐算法或“官方认证”；
- 发布者、来源和许可证都是包内自述；SHA-256 只证明内容完整性，不是数字签名或身份认证；
- 未提供远程代码、可执行插件、任意文件、静默联网或系统命令；这是本阶段的安全边界，不是待打开的隐藏能力；
- 尚无发布者签名、恶意包扫描、审核/下架、撤销列表、版权投诉和供应链事件响应；
- 未执行真实创作者模板供给、四周留存、分成与付费意愿验证；
- 原生文件选择器无法由当前浏览器控制器注入，已由真实 `File` 组件测试与服务协议测试补位；
- 本阶段未新增 iOS/Android 真机、Windows 桌面或新的真实窄屏浏览器矩阵；
- macOS 包未使用 Developer ID 签名且未 Apple 公证。

因此：本机与小范围内部试用为 GO；在线模板市场、公开下载、商业生态和应用商店发布为 NO-GO。
