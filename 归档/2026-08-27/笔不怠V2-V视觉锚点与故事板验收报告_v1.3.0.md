## 1. 阶段目标与结论

V2-V 对应原始调研 V2 的第四项“文字正典驱动的角色视觉锚点与故事板”。本阶段完成本地、可审计的视觉准备闭环：作者从已确认正典显式选择字段，建立可复核的视觉描述；导入图片先成为候选，只有作者接受后才与当时的正典版本绑定；场景故事板只保存镜头目的、连续性备注和视觉引用，不复制正文，也不让图片反向改写文字正典。

工程验收结论为通过。最终 `npm run check` 完成 30 个测试文件、108 项测试，TypeScript 与生产构建均通过；真实浏览器完成“正典—视觉锚点—场景故事板—顺序调整—来源回放”的可见闭环；macOS Apple Silicon 的 1.3.0 应用与 DMG 已构建、校验并完成本机启动冒烟。公开发布仍为 NO-GO：当前仅 ad-hoc 签名，尚无 Developer ID 签名、Apple 公证、Windows 构建和真实作者验证。

## 2. 主要交付

### 2.1 显式正典快照与隐私边界

- 视觉锚点只能从人物、地点或物品正典建立，名称必选，简介、别名和时态状态由作者逐项选择；
- 视觉描述清楚列出实际使用的字段，未选字段不会进入描述或哈希；
- `local_private` 实体在服务端直接拒绝，不依赖界面隐藏；
- 快照按规范化 JSON 计算 SHA-256，只覆盖实体类型、字段选择和值，不包含内部 ID 和更新时间；
- 未选字段变化不会误报过期，已选字段变化则令已接受绑定显示 stale，必须由作者刷新和重新确认。

### 2.2 内容寻址图片与候选决定

- 支持 PNG/JPEG 本地图片；服务端复核真实魔数、文件尺寸和像素尺寸，不信任文件名或浏览器声明的 MIME；
- 单图上限 10 MiB、总像素上限 100,000,000，阻断 MIME 欺骗、截断内容和超限图；
- 原始字节以 SHA-256 内容寻址，相同内容幂等复用，哈希相同但字节不一致按碰撞阻断；
- 导入后默认是 `pending` 候选；可接受、拒绝或被新定稿替代，决定均可追溯；
- 接受前重新计算当前正典哈希，防止用旧描述静默定稿；接受只建立资产—正典绑定，绝不修改名称、简介、别名、状态或正文。

### 2.3 无正文场景故事板

- 每个场景可建立一个故事板，卡片只保存镜头目的、连续性备注、视觉锚点、接受资产和正典哈希；
- 不保存场景正文、摘录或提示词，不形成第二份书稿；
- 支持新增、上移、下移和删除卡片，顺序变化不修改正文、正典或图片字节；
- 锚点尚无接受资产时仍可先做文字分镜，资产绑定保持为空，不伪造已定稿状态。

### 2.4 数据、备份、来源与界面

- migration v13 新增视觉锚点、正典快照、内容寻址资产、候选、故事板、卡片和视觉事件；v12→v13 升级前自动备份；
- API 覆盖锚点建立/刷新、候选导入/决定、资产读取、故事板建立/更新/排序/删除，全部由本地会话保护；
- 图片响应带真实 MIME、`nosniff` 与私有缓存约束，只通过本机回环服务读取；
- 普通 `bbd-backup-v2` 保存原始图片字节、锚点、候选、决定和故事板；恢复时重映射项目/实体/场景引用，并复验哈希、MIME、尺寸和正典；
- 项目清理同步删除视觉记录并回收孤立资产；来源工作台显示建立/刷新锚点、导入/接受/拒绝候选和更新故事板等事件；
- 交付工作台新增“视觉故事板”，提供三栏式正典、候选和故事板工作流，以及窄屏重排样式。

## 7. 已知限制与外部门

- 1.3.0 不连接任何远程图像 Provider，不提供在线生成、素材搜索、图片广场、点赞、下载量或媒体 CDN；
- 仅支持 PNG/JPEG，不支持 SVG/WebP、视频、分层源文件或批量媒体处理；
- SHA-256 与格式检查不代表版权授权、真实性、恶意内容检测、隐写检测、真人身份识别或安全审查；
- 未验证角色在数十张图中的跨图一致性，也未完成专业分镜师和真实长篇作者可用性研究；
- 本阶段未新增 iOS/Android 真机、Windows 桌面、真实窄屏或多个 macOS 大版本矩阵；
- 原生文件选择器无法由当前浏览器控制器注入，已由真实 `File` 组件测试和真实图片服务测试补位；
- macOS 包未使用 Developer ID 签名且未 Apple 公证，Windows 构建与代码签名仍未执行。

因此：本机与小范围内部试用为 GO；远程图像生成、公开下载、应用商店发布和商业视觉服务为 NO-GO。
